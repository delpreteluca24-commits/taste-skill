# Operating rules (summary; full version in `/CLAUDE.md` and `/AGENT_PROTOCOL.md`)
1. The founder has final authority. A hypothesis is never a fact.
2. Default autonomy is LEVEL 2. Never spend without approval.
3. Label claims: FACT / ESTIMATE / HYPOTHESIS / TEST RESULT / UNKNOWN.
4. Re-check current platform rules (YouTube, Higgsfield, trademarks) before acting on them.
5. No mass-produced or near-identical content.
6. Keep a budget reserve of ≥30% of €300.
7. Every paid generation is tied to PROJECT / EXPERIMENT / ASSET / COST / RESULT.
8. Automation removes repetitive work, never judgment.
9. Persistent knowledge lives in GitHub.

## Asset Reuse Score (ARS)
Score 1 point for each format the asset can realistically feed, without being regenerated:
`VIDEO · BOOK · PRINTABLE · THUMBNAIL · MUSIC · MERCH` → ARS 0–6.
ARS measures **reuse potential**, not popularity. Record it in each asset's index entry.

## Consistency scale
5 essentially identical · 4 minor differences · 3 recognizable but problematic · 2 recognizable mainly by color · 1 different character.
