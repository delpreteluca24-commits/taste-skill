# STUDIO OS

An operating system, run with AI help, for building an original **preschool IP (ages 0–5)**, codename **PROJECT M**. The IP comes first. YouTube is where we distribute and test first; it isn't the whole business.

> **Status (2026-09-29):** Gate 1 in preparation · concept and agent architecture approved by the founder (D-004) · Autonomy **LEVEL 2** · Spent **€0 / €300**
> See [`00_CORE/current-state.md`](00_CORE/current-state.md).

> 🔒 The concept's real name, character bible and stories are **held offline** until the OS moves to a private repo (D-003, FD-002). This public copy holds only non-sensitive infrastructure.

## How it works
Hypothesis → Test → Data → Learning → Decision → Next test. Speed of production is not the same as business progress.
